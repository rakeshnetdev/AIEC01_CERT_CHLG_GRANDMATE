# Synthetic Data & Evals — Overview

What test data the eval harness uses and how it's used. The harness was rebuilt after an audit
found the original version measured nothing — every "100%" it reported was either circular (ground
truth generated by the same code being graded) or fabricated (a default value returned when a
measurement failed, instead of an error).

## The data

| Dataset | Size | How it's built | Used for |
| --- | --- | --- | --- |
| **Detection dataset** | 151 positions | `evals/generate_synthetic.py` expands 16 base positions (10 general + 6 edge cases: promotion, castling, en passant, forced mate, stalemate, SAN disambiguation) into candidate moves, then labels each one with an **independent Stockfish oracle at depth 24** — never with the production classifier itself. | Scoring the production engine (depth 16) + classifier against ground truth it had no part in producing. |
| **Retrieval query set** | 135 queries | `evals/compare_retrievers.py` generates queries straight from the RAG corpus: exact names/terms, descriptions with the name stripped out, LLM-reworded paraphrases, and a few out-of-corpus negatives. Each query's correct chunk id is known by construction. | Comparing dense / BM25 / hybrid retrieval on Hit Rate and MRR. |
| **Judged-layer sample** | 2–3 positions | A small slice of the detection dataset driven through the real `/review` pipeline end to end. | LLM-as-judge scoring of faithfulness, coaching quality, and illegal-move rate. |

## How it's used

Two layers, split by cost:

1. **Deterministic layer** (free, runs every time). No LLM involved — just the Stockfish engine and
   the classifier, scored against the oracle-labeled dataset. Produces Detection F1 and Severity
   Accuracy. This layer can genuinely fail: corrupting the classifier's thresholds collapses F1 from
   ~0.95 to ~0.19, proving it's a real measurement and not a rubber stamp.
2. **Judged layer** (costs money, sampled on demand). Runs the small sample through the live graph
   and asks an LLM judge to score faithfulness and coaching quality, plus a deterministic legality
   check for the illegal-move rate.

Retrieval is measured separately from these two, by `compare_retrievers.py` against the query set
above.

## One rule that matters more than any number

Ground truth never comes from the code being graded, and a metric that fails to measure something
is reported as "not measured" — never silently defaulted to a passing score. That single rule is
what the harness rebuild was about, and it's what makes every number in `Deliverables.md` §5/§6
falsifiable rather than a rubber stamp: deliberately corrupting the classifier's thresholds
collapses Detection F1 from ~0.95 to ~0.19, proof the harness can actually fail.
